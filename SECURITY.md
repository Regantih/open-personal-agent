# Security Policy

This project publishes architecture guidance and draft specs for agents that handle payments, credentials, and personal data. Security issues in the guidance itself matter.

## Reporting

Please report vulnerabilities or unsafe recommendations privately through GitHub's **Report a vulnerability** feature (Security tab, private advisory). Do not open a public issue for:

- Patterns in the docs or specs that would enable credential leakage, unauthorized payments, or prompt-injection escalation.
- Weaknesses in the Risk Policy evaluation order.
- Ways the Open Memory Format could leak secrets or sensitive data.

Expect an acknowledgment within 7 days.

## Scope

This repository does not operate any service. Vulnerabilities in third-party projects or vendors listed here should be reported to those projects directly.
